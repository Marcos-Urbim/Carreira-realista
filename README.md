# Carreira Realista — Central do Clube

Site de apoio para acompanhar uma carreira do EA Sports FC.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: estilos e layout responsivo.
- `script.js`: funcionalidades, importação de jogos e OCR.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie estes três arquivos para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde o GitHub gerar o endereço do site.

O reconhecimento de texto usa Tesseract.js via CDN e precisa de conexão com a internet. Confira o texto reconhecido antes de importar porque OCR pode errar nomes, datas e placares.
